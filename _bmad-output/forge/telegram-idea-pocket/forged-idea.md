# Личный карман идей — закалённая версия

- **Что это**: отдельный Telegram‑карман только для идей (бот + Mini App), чтобы вытянуть идеи из общей каши Saved Messages и иметь одно чистое место, откуда их удобно забирать в другие системы.
- **Ключевая ценность**: при просмотре не нужно продираться через материалы и напоминалки; в веб‑/мини‑интерфейсе виден только список идей, сгруппированный по полкам‑источникам из `shelves.md`, с быстрым скроллом и копированием текста.
- **Режим извлечения (lock)**: дефолтный сценарий — не «вдохновение», а отбор и перенос идей наружу (в backlog, документы, задачи). Пользователь открывает список именно «забрать что‑то конкретное и пойти дальше».
- **Маркер обработки**: в v1 идея формально не требует статуса; как улучшение последующих версий допустим один общий булевый маркер «обработано», без детализации канала вывода.
- **Дисциплина содержания (lock)**: карман остаётся местом только для идей; ссылки, материалы, напоминалки и прочий шум по-прежнему живут в Saved Messages или других инструментах.
- **Трение захвата**: автор принимает, что трение записи «пришла идея — записал в карман» достаточно низкое и не требует дальнейшего микроспека шагов; отдельный карман оправдан именно выгодой на этапе извлечения.
