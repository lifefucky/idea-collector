# Полки источников

Полка — явный источник идеи. Указывается оператором, не выводится моделью. На захвате необязательна (CAP-4), в чате бота и в поле WebApp одинаково. После загрузки перечня задаёт группировку (CAP-3).

## Правила

| Откуда мысль | Полка |
|---|---|
| Агрегатор чужих проектов | Имя этого агрегатора |
| Чужой проект сам по себе | `чужие приложения` |
| Своя мысль | `идея собственная` |

## Агрегаторы (именная полка)

Каждый агрегатор — своя полка, не общая куча «агрегаторы».

- ProductHunt
- Product Radar
- Магазины приложений (каждый магазин — своя полка, по тому же правилу «агрегатор = имя»)
- YC / Y Combinator текущего года

Новый агрегатор, который оператор укажет явно, получает полку со своим именем.

## Чужие приложения

Одиночный чужой продукт, не агрегатор, всегда на одной полке `чужие приложения`. Не отдельная полка на каждое приложение.

## Собственная

Мысль без внешнего источника — полка `идея собственная`. Оператор пишет это явно, если указывает источник.

## Без полки

Идея без указанного источника остаётся в кармане и видна в перечне. Она не обязана попасть на полку в момент записи.
